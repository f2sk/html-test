# HTML Web Tools

ブラウザ上で動作する、カメラ合成ツールと画像背景除去ツールのコレクションです。
すべての処理はクライアントサイド（ブラウザ内）で完結するため、サーバーに画像がアップロードされることはありません。

## 🚀 ツール一覧

### 1. Web Cam Tool (カメラ合成)
カメラ映像に好きなPNG画像を重ねて撮影できるツールです。

*   **URL**: [https://f2sk.github.io/html-test/](https://f2sk.github.io/html-test/)
*   **主な機能**:
    *   **PNG合成**: 透過PNGを選択してカメラ映像の上に配置できます。
    *   **ジェスチャー操作**: 合成した画像はスワイプで移動、ピンチイン・アウトで拡大縮小が可能です。
    *   **露出調節**: スライダーでカメラの明るさを調整できます。
    *   **自動回転**: デバイスの向きに合わせて、合成画像の向きを90度単位で補正します。
*   **使い方**:
    1. ページを開きカメラの使用を許可します。
    2. 「PNG選択」から重ねたい画像を選びます。
    3. 画面上の画像をドラッグして位置を合わせます。
    4. 「撮影(JPG)」ボタンで、合成された画像を保存します。

---

### 2. Multi-Color Background Remover (画像編集・背景除去)
特定の色を透過させたり、画像の回転・切り抜きができる編集ツールです。

*   **URL**: [https://f2sk.github.io/html-test/editor.html](https://f2sk.github.io/html-test/editor.html)
*   **主な機能**:
    *   **クロマキー除去**: 緑・青・黒の背景をスライダー調整で綺麗に透過させます。
    *   **柔軟な回転**: 90度ごとの回転に加え、スライダーによる微細な角度調節が可能です。
    *   **矩形切り抜き**: 自由なサイズで画像をトリミングできます（UIの枠は保存されません）。
    *   **JPG/PNG対応**: 読み込みは両形式に対応し、透過PNGとして書き出せます。
*   **使い方**:
    1. 「画像を選択する」から編集したいファイルを選びます。
    2. 背景を消したい場合は「緑・青・黒」からモードを選び、しきい値スライダーを調整します。
    3. 必要に応じて「微回転」や「+90°/-90°」で向きを直します。
    4. 「枠を表示」を押し、ハンドルをドラッグして切り抜き範囲を決めたら「切抜実行」を押します。
    5. 「透過PNGとして保存」で結果をダウンロードします。
